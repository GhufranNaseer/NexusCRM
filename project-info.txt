1. PROJECT OVERVIEW
1.1 Project Name
NexusCRM

1.2 Type
Modern CRM & Client Relationship Management Platform (SaaS)

1.3 Purpose
Ek high-end CRM system banana jo companies ko help kare:
- Leads manage karne mein
- Clients track karne mein
- Sales pipeline control karne mein
- Team coordination improve karne mein
- Business analytics samajhne mein

1.4 Target Users
- Sales Manager
- Admin / Owner
- Support Team
- Marketing Team

2. PROBLEM STATEMENT
Companies struggle with:
- Scattered leads (Excel / WhatsApp / Email)
- No proper pipeline tracking
- Weak client history system
- No centralized communication
- Lack of performance analytics

3. SOLUTION
NexusCRM provides a unified CRM system:
- Centralized lead management
- Visual sales pipeline
- Client history tracking
- Task + activity system
- Analytics dashboard
- Messaging-style communication UI

4. SYSTEM ARCHITECTURE
4.1 Frontend
- React (Vite)
- Tailwind CSS
- React Router DOM
- Zustand / Context API
4.2 Charts
- Recharts
4.3 Backend
- Mock API (JSON) OR Node.js Express (optional)
4.4 Data Flow
User Action → UI Component → State Store → Mock API → UI Update → Analytics Refresh
